# Apna News 📰

MSN-style news portal — taaza khabrein, bilkul free.

## Kya hai is me

- **Live news** — free RSS feeds se (Dawn, BBC, Al Jazeera). Koi API key nahi chahiye.
- **Categories** — Top News, Pakistan, World, Sports, Business, Technology.
- **Search** — Bing search se jura hua.
- **Weather** — Lahore ka live temperature (free open-meteo API).
- **Ad slots** — header banner, sidebar (2), aur har 6 khabron ke baad in-feed ad. Details: `ADSENSE_SETUP.md`.

## Files

- `index.html` — poora layout + ad slots
- `styles.css` — design
- `app.js` — news load karne ka code
- `ADSENSE_SETUP.md` — ad lagane ka tareeqa (Urdu me)

## Chalana

Ye static website hai — koi server nahi chahiye. Render Static Site (free) par deploy karo ya GitHub Pages par.
